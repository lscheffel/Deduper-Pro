Deduper Extreme

Ferramenta avançada de deduplicação de arquivos com interface gráfica em PyQt, oferecendo modos Easy, Medium e Advanced para otimizar o gerenciamento de espaço em disco.

Manifesto

O Deduper Extreme visa fornecer uma solução eficiente e avançada para a deduplicação de arquivos, ajudando usuários a liberar espaço em disco de forma segura e inteligente. Nossa missão é simplificar o processo de identificação e remoção de arquivos duplicados, oferecendo flexibilidade através de múltiplos modos de operação e algoritmos de hashing robustos. Acreditamos em uma abordagem user-friendly, com interface gráfica intuitiva e opções avançadas para usuários experientes.

Arquivos

app_extreme.py

Arquivo principal da aplicação, contendo a interface gráfica em PyQt6 e a lógica básica de deduplicação. Inclui modos Easy, Medium e Advanced com configurações variadas.

core_extreme.py

Núcleo avançado do deduplicador com funcionalidades extras como hashing multimodal (MD5, SHA1, xxhash, CRC32), processamento paralelo e throttling adaptativo.

requirements.txt

Lista de dependências Python necessárias para executar a aplicação, incluindo PyQt5, openpyxl, xxhash e send2trash.

README.md

Documentação básica do projeto, incluindo funcionalidades, instalação e uso.

.gitignore

Arquivo para especificar quais arquivos e diretórios devem ser ignorados pelo Git.

EnvMaker.ps1

Script PowerShell para configuração automatizada do ambiente de desenvolvimento.

Análise

O Deduper Extreme é construído em Python, utilizando PyQt6 para a interface gráfica, garantindo uma experiência responsiva e moderna. A arquitetura é modular, com o núcleo de deduplicação separado da UI, permitindo fácil manutenção e extensão. Utiliza bibliotecas como hashlib para hashing padrão, xxhash para performance, e openpyxl para geração de relatórios XLSX. O processamento paralelo com concurrent.futures assegura eficiência em diretórios grandes, enquanto o cancelamento cooperativo e throttling adaptativo proporcionam controle e estabilidade.

Funções

Modo simplificado para usuários iniciantes, oferecendo seleção de diretório, algoritmo de hashing (MD5, SHA1, SHA256) e opções básicas de exclusão (lixeira ou manter ambos).

Modo intermediário com algoritmos adicionais, critérios de exclusão (permanente, lixeira, manter), critério de seleção (mais novo/antigo) e opção de relatório XLSX.

Modo avançado com todas as opções, incluindo comparação byte-a-byte após hashing, ajuste de tamanho de bloco e configurações finas para otimização.

Geração automática de relatórios detalhados em formato Excel, listando duplicatas encontradas, arquivos originais e hashes.

Possibilidade de cancelar o processo de deduplicação a qualquer momento, com parada segura e logging de progresso.

Sugestões

Faça backup dos arquivos importantes antes de executar a deduplicação. Use o modo Easy para testes iniciais. Monitore os logs para identificar possíveis erros. Para grandes volumes, considere o modo Advanced com throttling ativado. Organize seus arquivos em diretórios lógicos para melhor eficiência.
