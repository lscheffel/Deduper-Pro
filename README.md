# Deduper Extreme

Projeto avançado de deduplicação de arquivos com:
- Cancelamento cooperativo.
- Hashing paralelo (ThreadPool/ProcessPool).
- Relatórios .xlsx avançados com filtros, resumo e formatação.
- Presets salvos pelo usuário.

## Instalação
```
pip install -r requirements.txt
```

## Uso
```
python app_extreme.py
```
