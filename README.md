# Deduper Extreme

Ferramenta avançada de deduplicação de arquivos com interface gráfica em PyQt.

## Funcionalidades
- Modos Easy, Medium e Advanced
- Hash multimodal (MD5, SHA1, xxhash, CRC32)
- Checkpointing
- Throttling adaptativo
- Cancelamento cooperativo
- Relatórios avançados em XLSX
- Banco SQLite (no modo avançado)

## Instalação
```bash
pip install -r requirements.txt
```

## Uso
```bash
python app_extreme.py
```
